# 마석중 2026 점프밴드

학생용(`index.html`) + 교사용 관리(`admin.html`) 두 페이지로 구성된 앱입니다.
**과제 제출과 채점은 구글 클래스룸에서 진행**하고, 이 앱은 학급·모둠 관리와 학습자료 제공,
그리고 클래스룸으로 연결하는 역할을 합니다.

**주요 기능**
- 학급·학생 명단 관리, 모둠 무작위 배정 + 수동 조정 (학기 내내 유지)
- **전문가 주제(직소모형) 무작위 배정 + 수동 조정** — 학생 1명당 최대 2개까지 지정 가능, 모둠 현황판으로 한눈에 확인
- **학습자료 관리** — 12가지 기본동작 유튜브 링크·배점 등록, 학생 화면에 바로 노출
- **구글 클래스룸 연결** — 학생용 페이지의 버튼 하나로 클래스룸 이동, 제출 마감 안내

## 1. Firebase 프로젝트 준비

1. https://console.firebase.google.com 에서 새 프로젝트 생성 (또는 기존 프로젝트 재사용 — 컬렉션 이름만 겹치지 않으면 됩니다)
2. **Firestore Database** 만들기 (프로덕션 모드로 시작 → 아래 규칙 붙여넣기)
3. 프로젝트 설정 > 일반 > "내 앱"에서 웹 앱 추가 → `firebaseConfig` 값 복사
4. `firebase-config.js` 파일의 `firebaseConfig` 값을 복사한 값으로 교체
5. 같은 파일에서 `ADMIN_PASSWORD`를 원하는 비밀번호로 변경

> Storage는 쓰지 않습니다. 동작 이름·유튜브 링크·배점은 코드가 아니라 **admin.html의 "학습자료" 탭**에서, 구글 클래스룸 링크와 마감시간은 **"제출 설정" 탭**에서 관리합니다.

## 2. Firestore 보안 규칙

콘솔 > Firestore Database > 규칙에 아래 내용을 붙여넣으세요.
학생 인증이 없는 구조라 완전히 잠글 수는 없고, 학교 내부용 도구 수준의 규칙입니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /classes/{classId} {
      allow read: if true;
      allow write: if true;
      match /students/{studentId} {
        allow read: if true;
        allow write: if true;
      }
    }
    match /settings/{docId} {
      allow read: if true;
      allow write: if true;
    }
  }
}
```

## 3. 초기 데이터 세팅 순서

1. `admin.html` 접속 → 비밀번호 입력
2. **학급·학생 관리** 탭에서 학급 추가 (예: "1학년 1반" ~ "1학년 6반")
3. 학급 선택 후 학생 명단을 `번호,이름` 형식으로 한 줄씩 붙여넣고 일괄 등록
4. **모둠 · 전문가주제 배정** 카드에서 학급 선택 → 모둠 수/전문가주제 묶음 크기 입력
   - "모둠 무작위 배정" → "전문가 주제 무작위 배정" 순서로 누르면 한 번에 기본 배치가 끝납니다 (전문가 주제는 모둠별로 12가지 동작을 고르게 나눠 배정하므로, 모둠을 먼저 배정해야 의미가 있습니다)
   - 이후 아래 표에서 학생별로 모둠·전문가 주제(최대 2개)를 자유롭게 다시 조정할 수 있고, 선택 즉시 저장됩니다
   - 인원이 적은 모둠(예: 5명이 6개 주제를 나눠야 하는 경우)은 자동으로 한두 명이 2개 주제를 맡도록 배정됩니다
   - 아래 **모둠 현황판**에서 모둠별 인원과 전문가 주제 커버 현황을 바로 확인할 수 있습니다
5. **학습자료** 탭에서 12가지 동작 이름·유튜브 링크·배점을 등록하고 저장
   - 전체 재생목록 링크도 넣어두면 1차시 OT 때 한 번에 보여주기 좋습니다
6. **제출 설정** 탭에서 구글 클래스룸 초대(또는 과제) 링크와 제출 마감 일시를 입력하고 저장

## 4. 학생에게 배포

`index.html` 링크를 QR코드나 학급 게시물로 공유하면 됩니다. 로그인 없이
학급 → 번호/이름만 선택하는 구조라 접속 장벽이 낮습니다. 접속하면 본인 모둠·전문가 주제,
12가지 동작 학습영상, 그리고 구글 클래스룸으로 바로 이동하는 제출 버튼을 확인할 수 있습니다.

## 5. GitHub Pages 배포

```
git init
git add .
git commit -m "점프밴드 관리 시스템 배포"
git branch -M main
git remote add origin <본인 저장소 URL>
git push -u origin main
```

이후 저장소 Settings > Pages에서 `main` 브랜치를 Pages 소스로 지정하면
`https://<계정>.github.io/<저장소명>/` 로 학생용, `.../admin.html` 로 교사용에 접속할 수 있습니다.
파일을 수정한 뒤에는 저장소에서 다시 커밋(또는 재업로드)하면 1~2분 내 자동 반영됩니다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 학생용: 반/번호/이름 선택 → 내 모둠·전문가주제 확인 → 학습영상 시청 → 구글 클래스룸에서 제출 |
| `admin.html` | 교사용: 학급·학생 관리, 모둠/전문가주제 무작위 배정 + 수동 조정 + 현황판, 학습자료 관리, 구글 클래스룸 링크·마감 설정 |
| `firebase-config.js` | Firebase 연결 정보 + 관리자 비밀번호 설정 |

## 데이터 구조 요약

- `classes/{classId}`: `{ name, order }`
- `classes/{classId}/students/{studentId}`: `{ number, name, group, expertTopics }`
  - `expertTopics`: 전문가 주제 묶음 번호 배열(0부터 시작, 최대 2개). 실제 담당 동작은 각 번호마다 `번호 × topicSize` ~ `+topicSize-1` 구간
- `settings/config`: `{ deadline, topicSize, groupCount, playlistUrl, classroomUrl, movements: [{ name, youtubeLink, maxScore }, ...12개] }`

## 알아두면 좋은 동작 방식

- **제출·채점은 구글 클래스룸에서**: 이 앱은 더 이상 영상 제출이나 점수를 저장하지 않습니다. 학생용 페이지의 "구글 클래스룸에서 제출하기" 버튼이 "제출 설정" 탭에서 등록한 링크로 새 탭을 엽니다. 링크를 등록하지 않으면 버튼이 비활성화되고 안내 문구가 뜹니다.
- **모둠/전문가주제 배정**: "모둠 무작위 배정" / "전문가 주제 무작위 배정" 버튼으로 기본 배치를 한 번에 끝낼 수 있고, 그 아래 표에서 학생별로 언제든 다시 조정할 수 있습니다. 선택하면 그 즉시 저장되며 별도의 저장 버튼은 없습니다. 전문가 주제는 학생 1명당 최대 2개까지 지정 가능해서, 5명이 6개 주제를 나눠야 하는 모둠에도 대응됩니다. 무작위 배정은 모둠별로 12가지 동작을 고르게 나누는 방식이라, 전문가 주제를 무작위 배정하기 전에 모둠을 먼저 배정해두는 걸 권장합니다. 모둠 현황판이 선택할 때마다 바로 갱신되어, 모둠별 인원과 전문가 주제 분포를 한눈에 확인할 수 있습니다.
- **동작별 배점**: 학습자료 탭에서 동작마다 배점을 다르게 설정할 수 있습니다(예: 어려운 동작은 3점). 다만 채점 자체는 이제 클래스룸에서 이루어지므로, 이 배점은 학생에게 기준을 안내하는 참고용입니다.
- **학생 화면 학습영상**: 유튜브 링크가 등록된 동작만 "영상보기"가 눌리며, 누를 때마다 그 자리에서 재생됩니다(한꺼번에 다 안 불러와서 데이터 절약). 본인이 담당한 전문가 주제 동작에는 "내 담당" 표시가 붙습니다.
- **2차 평가(작품 발표)**: 이 앱에는 포함하지 않았습니다. 필요해지면 이후에 확장하면 됩니다.
